#########
Shortcuts
#########

Global
======

.. list-table::
   :header-rows: 1
   :widths: 22 78

   * - Shortcut
     - Action
   * - ``Ctrl+K`` / ``⌘+K``
     - Open the command palette.
   * - ``Alt+M``
     - Toggle between the main menu and the admin menu.
   * - ``Alt+W``
     - Create a new workflow.
   * - ``Ctrl+Enter``
     - Advance or submit the current step of a wizard.

Command palette
===============

.. list-table::
   :header-rows: 1
   :widths: 22 78

   * - Key
     - Action
   * - ``↑`` / ``↓``
     - Move through the suggestions.
   * - ``↵``
     - Select the highlighted suggestion.
   * - ``Tab``
     - Autocomplete the highlighted suggestion.
   * - ``⌫``
     - Leave a locked scope, on an empty input.
   * - ``Esc``
     - Close the palette.

.. note::
   A command only fires while a suggestion is **highlighted**. Typing a command
   out in full empties the list, and ``↵`` then does nothing — type a prefix and
   let the palette highlight the entry.

Workflow editor
===============

.. list-table::
   :header-rows: 1
   :widths: 22 78

   * - Shortcut
     - Action
   * - Drag
     - Pan the canvas.
   * - Scroll
     - Zoom in and out.
   * - Double-click
     - Open a node's configuration.
   * - Drag a node
     - Move it.
   * - ``Ctrl`` + drag
     - Duplicate a node instead of moving it.
   * - ``Ctrl`` + click
     - Select multiple nodes.
   * - ``Delete``
     - Delete the selected node.
   * - ``Ctrl+S``
     - Save the workflow.
   * - ``Esc``
     - Close the open menu, dialog or panel.

The same list is available in the editor under **Shortcuts** in the header menu.
