################
Create Workflow
################

The full workflow editor — canvas, connector/HTTP/operator steps, references and
enhancements, webhook parameters, aggregators, test run, templates, version
history — lives in the usage manual. Administrators use exactly the same UI as
regular project owners, so there is no separate "management" flow to describe
here. Refer to :doc:`../usage/workflows` for the step-by-step guide and keep
that article as the single source of truth.

.. note::
   Workflows were called *Connections* before 5.0, and a connection was limited
   to two connectors. See :ref:`usage-workflow-model` for what changed.
